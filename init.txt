SecOps FastMCP - guida operativa
=================================

PRIMA DI INIZIARE
-----------------
1. Apri PowerShell nella radice del progetto:
   Set-Location "S:\Cybersecurity_AgenticAI"
2. Usa soltanto target tuoi o esplicitamente autorizzati.
3. Per un target non locale aggiungi sempre --authorized.
4. Mantieni l'intero Cookie header tra virgolette.
5. Scegli una sola pipeline: deterministic oppure agentic.

SEGNAPOSTO
----------
<TARGET>         URL HTTP/HTTPS assoluto, ad esempio https://lab.example.test
<COOKIE_HEADER>  Cookie completo, ad esempio session=abc; role=student
<MODEL>          Modello Ollama, ad esempio qwen2.5:7b
<URL>            Endpoint dello stesso target per un test isolato
<PARAMETERS>     Parametri separati da virgole, ad esempio id,query
<JWT>            Token JWT da analizzare

1. AVVIO RAPIDO DEL LAB LOCALE INCLUSO
--------------------------------------
Prepara scanner, lab locale, ZAP e Ollama:
python .\initScript.py --with-lab --model qwen2.5:7
esempio:
python .\initScript.py --with-lab --model llama3.1:8b

Alla fine init stampa quattro comandi già pronti con il cookie appena creato:
- deterministic balanced
- deterministic deep
- agentic balanced
- agentic deep

Inizializzazione senza avviare il lab:
python .\initScript.py

Rigenera questa guida:
python .\initScript.py --commands-only

Inizializza e avvia direttamente una pipeline locale:
python .\initScript.py --with-lab --run deterministic --mode balanced
python .\initScript.py --with-lab --run agentic --model qwen2.5:7b --mode balanced

2. TARGET GENERICO - DETERMINISTIC
----------------------------------
Balanced autenticato, consigliato per i test normali:
python .\orchestratorDeterministic.py --target <TARGET> --cookies "<COOKIE_HEADER>" --auth-only --authorized --mode balanced

Deep autenticato, più lento e più esteso:
python .\orchestratorDeterministic.py --target <TARGET> --cookies "<COOKIE_HEADER>" --auth-only --authorized --mode deep

Solo superficie anonima:
python .\orchestratorDeterministic.py --target <TARGET> --authorized --mode balanced

Rimuovi --auth-only per eseguire sia il profilo anonimo sia quello autenticato.
Per 127.0.0.1, localhost e ::1 non serve --authorized.

3. TARGET GENERICO - AGENTIC
----------------------------
L'agente IA sceglie strumenti e richieste dalla superficie realmente scoperta.
Le azioni proposte vengono validate prima dell'esecuzione; non sono precompilate
con un piano fisso. Il fallback adattivo viene usato soltanto se Ollama non è
disponibile o non produce alcuna azione valida.

AI-planned balanced, consigliato:
python .\orchestratorAgentic.py --target <TARGET> --cookies "<COOKIE_HEADER>" --auth-only --authorized --model <MODEL> --max-rounds 2 --mode balanced

AI-planned deep, più esteso:
python .\orchestratorAgentic.py --target <TARGET> --cookies "<COOKIE_HEADER>" --auth-only --authorized --model <MODEL> --max-rounds 3 --mode deep --ai-timeout 720

Strict AI: termina invece di usare il fallback:
python .\orchestratorAgentic.py --target <TARGET> --cookies "<COOKIE_HEADER>" --auth-only --authorized --model <MODEL> --require-ai --max-rounds 2 --mode balanced

Modello già installato, senza pull automatico:
python .\orchestratorAgentic.py --target <TARGET> --authorized --model <MODEL> --no-model-pull --mode balanced

Endpoint Ollama personalizzato:
python .\orchestratorAgentic.py --target <TARGET> --authorized --model <MODEL> --ollama-url http://127.0.0.1:11434 --mode balanced

4. PREFLIGHT E DIAGNOSTICA
--------------------------
Preflight deterministic:
python .\orchestratorDeterministic.py --target <TARGET> --authorized --preflight-only

Preflight agentic:
python .\orchestratorAgentic.py --target <TARGET> --authorized --preflight-only

Sessione autenticata e passaggio attraverso ZAP:
python .\diagnose_sessions.py --target <TARGET> --cookies "<COOKIE_HEADER>"

ZAP passivo:
python .\diagnose_zap.py --target <TARGET> --cookies "<COOKIE_HEADER>"

ZAP attivo prioritizzato:
python .\diagnose_zap.py --target <TARGET> --cookies "<COOKIE_HEADER>" --active --timeout 300

Connettività Nikto/Python/Docker:
python .\diagnose_nikto.py --target <TARGET>

Login del solo lab locale incluso:
python .\diagnose_local_lab.py

5. DEBUG DI UN SOLO STRUMENTO
-----------------------------
Elenca strumenti, server MCP e funzioni:
python .\orchestratorDeterministic.py --list-tools

Forma generale:
python .\orchestratorDeterministic.py --target <TARGET> --cookies "<COOKIE_HEADER>" --authorized --tool <TOOL> --mode balanced

Strumenti host:       ffuf, zap, nuclei, nikto
Strumenti richieste:  arjun, sqlmap, dalfox, commix, traversal, idor
Strumenti speciali:   jwt, interactsh

Richiesta GET esplicita:
python .\orchestratorDeterministic.py --target <TARGET> --cookies "<COOKIE_HEADER>" --authorized --tool sqlmap --tool-url <URL> --method GET --parameters "<PARAMETERS>" --tool-timeout 180

Richiesta POST esplicita:
python .\orchestratorDeterministic.py --target <TARGET> --cookies "<COOKIE_HEADER>" --authorized --tool commix --tool-url <URL> --method POST --data "field=value&submit=1" --parameters "field"

Diagnostica ZAP senza scansione:
python .\orchestratorDeterministic.py --target <TARGET> --cookies "<COOKIE_HEADER>" --authorized --tool zap --diagnostic-only

JWT:
python .\orchestratorDeterministic.py --target <TARGET> --authorized --tool jwt --jwt-token "<JWT>"

OAST esplicito; FUZZ viene sostituito dal dominio di callback:
python .\orchestratorDeterministic.py --target <TARGET> --cookies "<COOKIE_HEADER>" --authorized --tool interactsh --interactsh-injection-url "<TARGET>/fetch?url=FUZZ" --method GET --parameters "url"

6. PROFILI DI SCANSIONE
-----------------------
fast      Controllo rapido e budget ridotti.
balanced  Copertura ampia con priorità ai controlli più importanti.
deep      Limiti maggiori, più richieste e copertura ZAP/Nuclei più estesa.

Deterministic e agentic condividono catalogo strumenti, limiti del profilo,
selezione delle richieste, controlli di sessione e formato del report.
L'agentic conserva la differenza essenziale: è l'LLM a scegliere il piano.

7. OPZIONI INIT
---------------
--with-lab          Avvia/verifica lab locale, ZAP e Ollama.
--run               none, deterministic oppure agentic; richiede --with-lab.
--model             Modello Ollama.
--mode              fast, balanced oppure deep.
--skip-scanners     Non installare/verificare gli scanner esterni.
--skip-preflight    Salta il preflight MCP live.
--commands-only     Riscrive init.txt, mostra la guida e termina.
--version           Mostra l'identificatore della build.

8. OPZIONI ORCHESTRATOR
-----------------------
Condivise:
--target --cookies --auth-only --authorized --mode --preflight-only
--ignore-preflight-errors --interactsh-injection-url

Solo deterministic:
--tool --list-tools --tool-url --tool-timeout --method --data --parameters
--jwt-token --diagnostic-only

Solo agentic:
--model --ollama-url --no-model-pull --require-ai --max-rounds --ai-timeout

Diagnostica ZAP:
--target --cookies --active --timeout

9. NUCLEI
---------
Aggiorna motore e template ufficiali:
nuclei -update
nuclei -update-templates

Conta i template installati in PowerShell:
nuclei -tl -silent -nc -disable-update-check | Measure-Object -Line

Riparazione e registrazione del percorso esatto:
python .\initScript.py --with-lab --model <MODEL>

Il percorso selezionato viene scritto in .secops_runtime.json e passato
esplicitamente al server MCP Nuclei.
